# MacroTex

Tex's Windows macro app: create and record keyboard/mouse macros, bind them to any key, preview them on a virtual keyboard, and warm up in the built-in 3D aim trainer.

## Download

Get the latest **MacroTex-Setup-x.y.z.exe** from [Releases](../../releases/latest), run it, and follow the steps.

- Windows may show **"Windows protected your PC"**, because MacroTex isn't code-signed yet. Click **More info → Run anyway**.
- No administrator password is needed.
- Once installed, MacroTex **updates itself**. Updates are digitally signed by Tex, and MacroTex refuses any update that isn't.

Some online games' anti-cheat systems forbid macro tools. Check a game's rules before using MacroTex with it.
